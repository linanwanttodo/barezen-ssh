设计语言声明

本次改版以「控制台石墨」为概念：深石墨色背景降低长时间运维的视觉负荷，青绿色作为唯一功能强调色，所有层次通过 1px 实线边框与明度差异建立，不使用渐变、发光或玻璃拟态。界面保持高信息密度，但保留充足的呼吸间距。

6. 动效原则

  • 动效仅用于状态变化反馈，时长控制在 150–250ms。
  • 使用透明度淡入淡出（fade）表示内容切换，不使用位移、缩放或旋转做装饰。
  • 焦点环、选中态、加载指示器为唯一常驻动画，帧率目标 60fps。
  • 不引入粒子、呼吸光晕、视差或背景动态纹理。

终端区域处理方案

终端是产品价值核心，其渲染区由 JediTerm（Swing 组件）内嵌 Compose 提供。设计需保证终端区域始终是一块完整的、可独立滚动的矩形，不可被其他 UI 元素遮挡或分割为异形。

  • 位置与尺寸：终端区域位于标签条下方、状态栏上方，占满内容区剩余宽高。最小宽度 1180px 时，除去 200px 导航与 24px 边距，终端区宽度不小于 932px；高度随窗口变化。
  • 分屏：当用户执行「向右拆分」或「向下拆分」时，将终端区按格子划分为多个等大的 JediTerm 子区域，每个子区域独立滚动、独立会话，边框使用 1px solid border 分隔。
  • 标签：标签条位于终端区正上方，高度 36px；活动标签以背景色 elevated 区分，不使用下划线或渐变。
  • AI 侧栏：侧栏位于终端区右侧，宽度 280px（推荐 1440px 布局），与终端区同高；通过标签条上的「助手」按钮收起/展开，非悬浮、不覆盖终端内容。
  • 状态栏：固定高度 28px，位于终端区底部；承载连接状态、服务器名、SSH 往返延迟，以及占位中的负载/内存/运行时间指标。
  • 字体：终端内统一使用 JetBrains Mono 13px；UI 主题不派生终端调色板，终端 16 色由 JediTerm SettingsProvider 独立注入。

动效原则与 reduced-motion 声明

  • 通用时长：150–250ms；使用 opacity 淡入淡出表达内容切换。
  • 加载态：使用旋转进度图标（progress_activity），时长不限，但仅出现于连接/加载期间。
  • 焦点环：2px solid accent，无过渡，确保键盘用户即时可见。
  • 禁止项：悬浮放大、悬浮变色、阴影扩散、背景渐变动画、粒子、呼吸光晕。

prefers-reduced-motion 处理

常规动效减弱模式下
内容切换淡入淡出直接切换，不透明度变化设为 0ms
加载旋转图标保留静态进度图标或文字「加载中…」
焦点环出现保持可见，无过渡
错误横幅出现直接显示，无滑入/淡入
